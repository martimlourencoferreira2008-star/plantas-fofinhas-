# Verde — Aplicação Web de Gestão de Plantas

Aplicação desenvolvida em **HTML**, **CSS** e **JavaScript**, com base de dados **localStorage**.

## Como executar

1. Abra a pasta `Verde-App`.
2. Abra `index.html` no browser (Chrome ou Edge recomendados).
3. No Windows, pode usar `abrir.bat`.

## Conta de demonstração

- Email: `demo@verde.pt`
- Palavra-passe: `demo123`

Também pode **criar uma conta nova** em «Criar conta».

## Estrutura (fluxo da aplicação)

Capa → Login / Registo → Menu → Armário (pesquisa, filtros, +) → Editar/Eliminar  
Menu → Perfil (definições) | Alertas | Início
